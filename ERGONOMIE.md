# Ergonomie — critères de Bastien et Scapin

Comment chaque critère est appliqué sur le portfolio.

| Critère | Application |
|---|---|
| **1. Guidage** | Menu horizontal avec la section en cours surlignée ; chapitres numérotés 00 à 04 ; consignes sous le champ de recherche et dans Contact (« indiquez le type de projet, le délai et votre budget ») ; retours immédiats : critères de recherche affichés à la frappe, « Adresse copiée », bouton pause qui change d'état ; contrastes vérifiés dans les deux thèmes, particules atténuées derrière le texte sur mobile. |
| **2. Charge de travail** | Contact en un clic (WhatsApp, e-mail avec objet pré-rempli, copie de l'adresse) ; une seule page ; démarche résumée en 4 étapes ; pas de doublon entre le titre et la consigne de Contact. |
| **3. Contrôle explicite** | Écran de démarrage court (0,7 s) et interruptible par un clic ou une touche ; bouton pour suspendre et reprendre les animations, choix mémorisé ; plus de boutons qui bougent sous la souris ; curseur du système conservé. |
| **4. Adaptabilité** | Plusieurs chemins vers chaque section (menu, boutons, pied de page, touches 0 à 4) ; thème clair ou sombre ; français ou anglais ; réglage « réduire les animations » du système respecté. |
| **5. Gestion des erreurs** | Recherche : message qui explique quoi essayer quand rien n'est reconnu, bouton Effacer ; copie de l'adresse : solution de repli et message clair si la copie échoue ; site lisible même sans JavaScript ou sans 3D. |
| **6. Homogénéité** | Même bouton principal orange pour les actions principales, mêmes pastilles pour les liens secondaires, même style de titres et de numéros dans chaque section. |
| **7. Signifiance** | Libellés qui disent ce qu'ils font : « Voir les réalisations », « Écrire sur WhatsApp », « Copier l'adresse » ; icônes soleil, lune, pause et lecture avec infobulle et libellé accessible. |
| **8. Compatibilité** | WhatsApp en premier canal, montants en FCFA, français par défaut, conception pensée d'abord pour le mobile. |
